💡 Bienvenue dans Find-a-Business

Pour afficher tes idées, l'application a besoin d'une clé d'accès GitHub limitée à ton dépôt. Tu ne la crées qu'une fois.

  1. Ouvre github.com/settings/personal-access-tokens/new
  2. Token name : find-a-business-app · Expiration : 1 an (366 days)
  3. Repository access : Only select repositories → choisis find-a-business
  4. Permissions → + Add permissions → coche Actions, Contents et Variables, puis passe chacune de Read-only à Read and write
  5. Generate token, copie la clé (elle commence par github_pat_) et colle-la ci-dessous.

La clé est enregistrée uniquement sur cet ordinateur.
